# test-theodoric-3

Please see [docs](https://docs.dfoundation.io/networks/) -> Test-Theodoric-3 for more information.

- Chain ID: `test-theodoric-3`
- Genesis time: `2026-10-20T09:00:00Z`
- Protocol version: `v1.0.0-rc.2`

## Files

- `testnet.config.json` — genesis-gen input config (source of truth).
- `pre-genesis.json` — pre-gentx genesis emitted by `genesis-gen -config testnet.config.json -out pre-genesis.json`. Validators collect gentxs against this; the final `genesis.json` is produced with `-gentx-dir`.
- `issuers.json` / `credentials.env` — VC template issuer DIDs + JWKs (generated by `create_templates.sh`).

## Creating your gentx

Copy `pre-genesis.json` into your node home as the genesis file first — gentxs must be created against it:

```bash
cp pre-genesis.json $DCHAIN_HOME/config/genesis.json
```

Then create the gentx. The staking/bond denom is `adt` (18 decimals, 1 DT = 10^18 adt). Each genesis validator is allocated 30,000,000 DT; the example below self-delegates 10,000,000 DT with a minimum self-delegation of 1 DT. Note the network enforces a minimum commission rate of `0.05`.

```bash
dchain genesis gentx <key-name> 10000000000000000000000000adt \
  --chain-id="test-theodoric-3" \
  --moniker="<moniker>" \
  --identity="<keybase-identity>" \
  --website="" \
  --details="" \
  --security-contact="" \
  --commission-rate="0.05" \
  --commission-max-rate="0.1" \
  --commission-max-change-rate="0.01" \
  --min-self-delegation="1000000000000000000" \
  --ip="<public-ip>" \
  --node-id=$(dchain cometbft show-node-id)
```

`--ip` and `--node-id` set the gentx memo (`<node-id>@<ip>:26656`), which is used to build the persistent peer list — make sure they match the address your node will be reachable at.

The signed gentx is written to `$DCHAIN_HOME/config/gentx/`. Submit it as a PR adding the file to this network's [`gentx/`](./gentx/) directory.

## Required node config (before starting your node)

`dchain init` writes defaults that are wrong for this network — every validator must change both settings below.

**1. `DCHAIN_HOME/config/app.toml`** — set the EVM chain ID to **430** (the default is 262144):

```toml
[evm]
# EVMChainID is the EIP-155 compatible replay protection chain ID. This is separate from the Cosmos chain ID.
evm-chain-id = 430
```

**2. `DCHAIN_HOME/config/config.toml`** — use the app-side mempool, required for EVM tx handling (the default is "flood"):

```toml
[mempool]
type = "app"
```

**3. Adding your Verifiable Presentation**:

> **If you do not have the VP, you will not be able to propose / vote on blocks and will be jailed.**

Add the verifiable presentation to the config before starting the node:

Add VP as a file in the node home as `DCHAIN_HOME/config/validator_vp`.
